# Supporting material

Documents written alongside the paper for readers who asked for something
shorter or more specific than the manuscript.

| file | what it is |
|---|---|
| [`one_pager.md`](one_pager.md) | The project on one page: the results, one figure each, and what underwrites them. |
| [`questions.md`](questions.md) | Three methodological questions, each with my position and what would change it. |
| [`pit_loss_rule_brief.pdf`](pit_loss_rule_brief.pdf) | One page on the endurance pit-loss result: the measurement, the correlation data, the figure and the weak points. Generated by `scripts/make_outreach_brief.py`, so every number is read from an artifact. |
| [`overcut_feasibility_brief.pdf`](overcut_feasibility_brief.pdf) | One page on what Salminen's overcut defence requires at the degradation rates fitted here. Generated by `scripts/make_salminen_briefs.py`. |
| [`d1_defence_brief.pdf`](d1_defence_brief.pdf) | One page on the position-keeping defence tested against 357 real decisions, including the three defects found while building the test. Same generator. |
| [`csas_2027_abstract.md`](csas_2027_abstract.md) | Abstract for the Carnegie Mellon Sports Analytics Conference 2027. |
| [`fastf1_issue.md`](fastf1_issue.md) | The bug report filed against FastF1 (#966), which became the `exact_match` parameter in FastF1 3.9.0. |
| [`fastf1_repro.py`](fastf1_repro.py) | Self-contained reproduction for it; runs on a clean `pip install fastf1`. |
